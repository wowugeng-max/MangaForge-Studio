# 小说工作台 UI 升级设计(2026-08-13)

## 目标

1. 信息层级重构:任何时刻"下一步该做什么"一眼可见,单屏徽章/按钮数量大幅收敛。
2. 正文编辑区专业化:在现有 CodeMirror 6 基础上补齐专业写作编辑器能力。
3. 顺带偿还前端技术债:拆分 god-hook 与巨型 CSS,不动后端与数据流协议。

## 已确认的决策

- 范围:UI 重组 + 前端状态层/样式拆分(纯前端,不动后端)。
- 策略:渐进式,保留"小说目录 / 写作中心 / 参考资料"三栏骨架,分批可发布。
- 信息优先级:以"下一步行动"为第一信息;写作时正文优先,收尾时质量与下一步优先。
- 编辑器功能(7 项):打字机模式+段落聚焦、质检内联批注、修订双栏对照、章内大纲导航、查找替换(本章+全书)、字数目标进度+码字速度、命令面板+快捷键体系。
- 不做:全屏无干扰模式(现有沉浸模式已覆盖)。

## 一、信息层级重构

### 现状问题

章节头部同屏并列 10+ 个徽章与按钮(状态、材料%、字数、复检、重写、版本、章长预设、展开详情、可写、待质检、交稿需复检),加上工作流步骤条与质检面板,视觉重点被稀释。

### 方案

1. **单一主行动**。`chapter-workflow-presenter.ts` 已输出唯一 `primaryAction` + `secondaryActions`,渲染层贯彻它:
   - 章节头部只保留一个大号主按钮(生成正文/复检/一键修订/同步故事状态/写下一章,随阶段变化)。
   - 其余动作(重写、版本、章长预设、显示设置等)全部收进主按钮旁的次级下拉菜单。
2. **状态行收敛**。章节头部第二行只保留:`阶段 pill(未写/已写待复检/待修订/可写下一章…) + 字数/目标进度`。材料%、可写/待质检计数、交稿风险等合并为一个"详情"popover 入口。
3. **交付状态芯片收敛**。`workspace-center-delivery-status-chips.tsx`(621 行)折叠为单个摘要芯片 + popover 展开明细。
4. **质检修订面板摘要化**。`workspace-center-quality-revision-panel.tsx` 折叠态只显示一行:`分数 · 问题数 · [主修复动作]`;旧报告过期警示保留在摘要行。展开态维持现有全部能力。
5. **工作流步骤条**改为轻量进度示意(当前步高亮、已完成打勾、未到达淡化),视觉权重低于主按钮。

## 二、编辑器专业化(CodeMirror 6)

| 功能 | 实现要点 |
|---|---|
| 打字机模式 + 段落聚焦 | CM 扩展:光标行垂直居中(scrollIntoView + scrollMargin);非活动段落 opacity 淡化(decoration)。工具栏开关,localStorage 持久化 |
| 质检内联批注 | 质检报告 issues 按 evidence 文本匹配定位正文(找不到降级为段落级/不显示);Decoration 波浪线 + gutter 标记;hover Tooltip 摘要;点击联动质检面板对应项 |
| 修订双栏对照 | `@codemirror/merge` MergeView;入口:修订任务完成后"查看对照"、版本面板"与当前对照";支持逐块接受/拒绝后回写 chapter_text(走既有 autosave/version 链路) |
| 章内大纲导航 | 数据源:场景卡(scene_list)+ 正文空行分段;编辑器左侧细栏列表,点击 scrollIntoView 定位;当前视口段高亮 |
| 查找替换 | 本章:`@codemirror/search`(汉化 phrases);全书:章节目录抽屉内加搜索页,前端跨章检索(复用已缓存章节,未缓存的按需拉取),命中跳章定位 |
| 字数目标进度 | 章节头进度显示 `当前字数/目标字数`(目标沿用标准章/长章/自定义预设);会话新增字数与近 10 分钟码字速度,数据仅前端统计 |
| 命令面板 + 快捷键 | Cmd+K 命令面板:聚合 presenter 全部动作 + 切章 + 切区域 + 打开各面板;快捷键:Cmd+S 立即保存、Cmd+F 查找、Cmd+Enter 主行动、`?` 快捷键速查表;快捷键注册集中于单一 keymap 模块 |

## 三、支撑性重构

1. `shell/use-novel-workspace-base-model.tsx`(1222 行)按领域拆分:章节工作流 / 质检 / 编辑器偏好 / 任务;组合层只做拼装,`workspaceViewDeps` 接口保持兼容,消费方逐步迁移。
2. `WorkspaceCenter.css`(4197 行)按组件就近拆分(editor / action-bar / quality-panel / delivery / context-strip),统一使用 `styles/novel-tokens.css` 变量,删除死样式。`AutoCreationDirectorWorkspace.css`(3338 行)不在本次范围。
3. 编辑器偏好(字体/行高/打字机/段落聚焦)统一为 `useEditorPreferences` hook + 单一 localStorage key。

## 四、分批交付

| 批次 | 内容 | 备注 |
|---|---|---|
| 1 信息层级 | 章节头收敛、单一主行动、状态行、交付芯片收敛、质检面板摘要化、步骤条轻量化 | 视觉收益最大、风险最低 |
| 2 编辑器基础 | 命令面板+快捷键、查找替换、字数进度+码字速度、打字机/段落聚焦 | 纯前端新增,互不依赖可并行 |
| 3 深度集成 | 内联批注、修订 diff 对照、章内大纲导航 | 依赖质检报告/版本数据结构 |
| 4 重构收尾 | god-hook 拆分、WorkspaceCenter.css 拆分、偏好 hook 合并 | 与 2/3 并行推进,最后清尾 |

每批独立可发布;每批配套测试(presenter 推导逻辑单测、CM 扩展单测),现有测试保持全绿。

## 验收标准

- 写作页默认视图中,章节头部可点击元素 ≤ 5 个(主按钮、次级菜单、详情 popover、步骤条、目标进度)。
- 任意工作流阶段,主按钮文案与 presenter `primaryAction` 一致。
- 7 项编辑器功能各有开关或快捷入口,且不影响自动保存与版本链路。
- `bun run build:web` 通过;`ui/web` 相关测试全绿。
